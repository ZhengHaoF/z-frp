# ADR-0002: 服务端与客户端都用 Node.js

- 状态：已接受
- 日期：2026-11-16

## 背景

服务端技术栈用户已指定为 Node.js。客户端可选：两端都 Node、Go 客户端、或多端并进。

## 决策

frps 与 frpc 都用 Node.js 实现。

## 理由

- 两端共用协议编解码、帧格式、消息类型定义，避免协议写两遍带来的不一致 bug。
- 开发者熟悉 Node，调试和迭代最快。
- 本项目规模是"自己 + 少数可信的人"，不需要 Go 单文件二进制分发带来的部署优势。

## 后果

- 客户端运行需要 Node 运行时；分发到无 Node 的机器需要先装 Node。若将来需要轻量分发，再评估 Go 客户端（那时要新建协议跨语言一致性测试）。
- Node 单线程事件循环：一个写坏的客户端可能拖慢整个 frps。需要用 worker/cluster 或严格的背压与超时机制兜底（见待决项）。
