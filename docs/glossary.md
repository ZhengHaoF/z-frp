# 术语表

本项目（z-frp）中的用词约定。一词一义，避免讨论时鸡同鸭讲。

## 角色与组件

- **frps（服务端）**：运行在有固定公网 IP 的 Linux VPS 上，监听公网入口，负责认证、路由、转发。技术栈 Node.js。
- **frpc（客户端）**：运行在本地开发机上，主动连出到 frps，把本地服务注册上去，并把数据转给本地服务。技术栈 Node.js。
- **本地服务（origin）**：frpc 背后真正提供服务的进程，比如本地的 `localhost:5173` 或 `localhost:3306`。
- **访问者（visitor）**：从公网访问暴露出来的服务的人或程序。当前范围是"自己 + 少数可信的人"。
- **Caddy**：跑在 VPS 最外层的反向代理，负责 HTTPS 证书签发/续期、TLS 终止、把请求转给 frps。
- **隧道（tunnel）**：frpc 与 frps 之间那条长期存活的 WebSocket 连接。所有控制信令和业务数据都跑在它上面。

## 数据面概念

- **流（stream）**：隧道内的一条逻辑子连接，用 `streamId` 标识。一条隧道里可以并发多条流。
- **多路复用（multiplexing）**：在单条 WebSocket 连接上同时承载多条流的技术。本项目自研极简帧格式实现。
- **入口（ingress）**：访问者进入系统的方式。本项目有两种：**HTTP 入口**（经 Caddy，按 Host 头路由）和 **TCP 入口**（frps 直接监听端口，供数据库等原生 TCP 客户端连接）。
- **固定域名路由**：每条 HTTP 隧道登记一个完整域名（如 `a.b.com`），该域名的 A/CNAME 指向 VPS；frps 读 Host 头精确匹配到对应隧道。新增域名要同时加 DNS 记录和 Caddy 站点名（见 ADR-0012）。
- **代理类型**：`http` 代理走 HTTP 入口；`tcp` 代理走 TCP 入口。由 frpc 注册时声明。

## 安全概念

- **接入认证**：frpc 连 frps 时证明自己身份的机制（详见 ADR-0005，待定）。
- **TLS 终止**：TLS 在 Caddy 处解密，Caddy 到 frps、frps 到 frpc 之间是另一段链路。是否再加应用层加密见待决项。
- **暴露面**：公网可达的端口与域名集合。最小化暴露面是默认原则。

## 明确不用的词

- **"云服务器" / "VPS" / "入口机"**：指同一台机器，统一叫 **VPS**。
- **"穿透" / "打洞" / "映射"**：统一叫 **暴露（expose）**，比如"把本地 5173 暴露成 `a.b.com`"。
